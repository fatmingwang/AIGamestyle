ComfyLive: make a song from a JSON file

One command, one JSON file, one MP3. ComfyLive checks whether ComfyUI is running and starts it if it is not.

Steps
  1. Check what you need
  2. Build ComfyLive (once)
  3. Write a song file
  4. Generate the song
  5. Find the result
  6. Make the same song again, or a new take
  7. Change the style, voice and lyrics
  8. Stop ComfyUI when you are done
  9. If something goes wrong

3Write a song file

Copy the example and edit it, or create a new .json file anywhere. A song file looks like this:

my_song.json

{
    "name": "My Song",
    "tags": [
        "1990s R&B pop ballad",
        "powerful female soprano lead",
        "melismatic vocal runs",
        "lush strings",
        "Rhodes electric piano",
        "slow romantic groove"
    ],
    "lyrics": [
        "[Verse 1]",
        "Every evening when the lights turn low",
        "There's a corner booth that only we know",
        "",
        "[Chorus]",
        "Oh, you and me, this quiet flame",
        "We never say each other's name"
    ],
    "duration": 289,
    "bpm": 64,
    "keyscale": "Eb major",
    "language": "en"
}
KeyWhat it does
nameA name for the song (optional).
tagsStyle, instruments and voice. An array, or one string separated by commas.
lyricsOne line per entry. Section tags such as [Verse 1], [Chorus], [Bridge] and [Outro] go on their own lines. Use "" for an empty line.
durationLength in seconds. 289 = 4:49.
bpmTempo. 60–75 for a slow ballad, 100–130 for dance.
keyscaleKey, e.g. "Bb major", "D minor".
language"en", "zh", "ja", "ko", ...
seedOptional. A fixed number gives the same song every time. Without it, every run is a new take.
_commentAny key that starts with _ is a note for you and is ignored.

Any other input of the ACE-Step graph also works, for example cfg_scale, temperature or steps.

Describe a voice; don't name a real singer in the tags. Use lyrics you wrote or have the rights to.

4Generate the song

Open Command Prompt (cmd) and run:

cd /d D:\Work\MagicTowerOfSoercer\TOMS\AIGamestyle\ComfyLive\build\Release
ComfyLive.exe --song=D:\Songs\my_song.json --out=D:\Songs\my_song_take1.mp3 --keep-comfy

In PowerShell, put .\ in front of the program:

cd D:\Work\MagicTowerOfSoercer\TOMS\AIGamestyle\ComfyLive\build\Release
.\ComfyLive.exe --song=D:\Songs\my_song.json --out=D:\Songs\my_song_take1.mp3 --keep-comfy

What you will see:

no ComfyUI at 127.0.0.1:8188: starting the local one     (only if it was not running)
  ComfyUI is up after 18 s
  WebSocket open
progress 0 %
...
progress 100 %
song: D:\Songs\my_song_take1.mp3
settings: D:\Songs\my_song_take1.json
made in 124.2 s
DONE

DONE (exit code 0) means the song was written. The first run takes longer because ComfyUI has to start and load the model. Later runs take about 40–60 s for a 4–5 minute song.

Options

OptionWhat it does
--song=file.jsonRequired. A song file (step 3), or the settings file saved with an earlier song (step 6).
--out=file.mp3Where to write the song. Without it, the song goes next to the JSON file as <name>_<date-time>.mp3.
--keep-comfyKeep ComfyUI running afterwards, so the next song starts at once. Without it, a ComfyUI that ComfyLive started is closed at the end. A ComfyUI that was already running is never closed.
--random-seedA new take, even from a settings file or a song file with a seed.
--server=host:portAnother ComfyUI address (default 127.0.0.1:8188).

5Find the result

Each run writes two files side by side:

FileWhat it is
my_song_take1.mp3The song.
my_song_take1.jsonIts settings file: the exact graph, values and seed that made this take. Keep it if you like the take.
ComfyLive refuses an --out whose settings file would overwrite your song file (e.g. --song=my_song.json --out=my_song.mp3). Pick another name, such as my_song_take1.mp3.

6Make the same song again, or a new take

The exact same take (from its settings file)

ComfyLive.exe --song=D:\Songs\my_song_take1.json --out=D:\Songs\my_song_copy.mp3

A new take with the same settings

ComfyLive.exe --song=D:\Songs\my_song_take1.json --out=D:\Songs\my_song_take2.mp3 --random-seed

A new take from the song file (no seed in it: every run differs)

ComfyLive.exe --song=D:\Songs\my_song.json --out=D:\Songs\my_song_take3.mp3

Generate a few takes and keep the best one: the model doesn't always follow the voice words.

7Change the style, voice and lyrics

Edit only tags to give the same lyrics another sound. Two styles we have used:

Soundtags
1970s soul, male baritone1970s Philadelphia soul ballad, deep raspy baritone male lead, gospel-tinged pleading vocal, lush string section, Rhodes electric piano, vibraphone, soft horns, brushed drums, warm bass, slow romantic groove
1990s R&B, female soprano1990s R&B pop ballad, powerful female soprano lead, wide vocal range, whistle register high notes, melismatic vocal runs, gospel-tinged belting, lush strings, Rhodes electric piano, soft drums, warm bass, emotional key-change build

Useful voice words: male vocals, female vocals, breathy voice, raspy, soprano, baritone, falsetto, choir backing vocals.

For a higher or lower key without generating again, use the headless transpose command or the window's Transpose (see ComfyLive\README.md).

8Stop ComfyUI when you are done

With --keep-comfy, ComfyUI keeps running in the background and holds GPU memory. To stop it, find the process on port 8188 and end it:

netstat -ano | findstr :8188
taskkill /PID <the number at the end of the LISTENING line> /F

Or end the python.exe process from ComfyUI's .venv in Task Manager.

9If something goes wrong

Exit codeMeaningWhat to do
0The song was written—
1ComfyUI could not startRead AIGamestyle\_comfyui\comfylive_server.log.
2Bad file or optionCheck the path, the JSON syntax, and the input names in the message.
4No ComfyUICheck --server, or let ComfyLive start the local one.
5ComfyUI refused the graphUsually a missing model: see step 1.
6No audio came backTry again. Check the ComfyUI log.
7ComfyUI failed while runningOften out of GPU memory: close other GPU programs, or use a shorter duration.
8Stopped—

To check that everything works without making a long song:

ComfyLive.exe --headless-test --start --music

It ends with ALL CHECKS PASSED.
