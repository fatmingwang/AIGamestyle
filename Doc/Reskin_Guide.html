Reskinning Spine and textures with AIGamestyle

How the pipeline gives a finished slot game a new art style without touching its layouts or animations, what it cannot do, and the choices you make for each reskin. The decision panel turns your choices into plan settings for the next pass.

What a reskin keeps

Every new picture drops into the game as is. The pipeline keeps four things fixed:

  • File name, folder and pixel size. Prefabs, auto-atlases and layouts still find the files.
  • The alpha channel. The original transparency is copied back, so outlines, masks and hit areas line up.
  • Spine data. The .atlas and skeleton .json are never edited. Only pixels inside each part's rectangle change.
  • Letters, numbers and glyphs. They are restyled gently, or their original pixels are put back.

So a reskin changes materials, colours and patterns inside each shape. A shape itself never changes.

How a texture is restyled

Picture on grey, long side 1024→ SDXL img2img (Juggernaut XL)+ ControlNet canny holds outlines+ IP-Adapter reference (optional)→ Back to exact size→ Original alpha + edge repair

Each picture gets a kind. A kind sets two numbers. Strength (denoise) is how far the picture may move toward the prompt. Outline hold (ControlNet) is how hard the original edges are kept.

KindStrengthOutlineUse for
object0.750.60Things that can change freely: dragons, trees, clouds, ingots
tile0.750.85Mahjong tiles. Body restyled, original coloured glyph put back (keep_glyph)
badge0.550.85A symbol whose character or word must survive (a scatter character, WILD)
frame0.700.70Reel frames, panels, bars
scene0.620.50Full backgrounds
text0.45–0.600.85Buttons with icons, words such as BIG WIN
keep——Unchanged: rules pages, black layers, effect sheets

Per-picture options

FieldWhat it does
subjectOne line describing the same object in the new style. Example: "a carved slate stone mahjong tile, the green character inlaid in jade".
denoise, controlOverride the kind's strength and outline hold for one picture.
cropRestyle only the visible area. A 3000 × 1280 frame with 900 px of content keeps full detail instead of shrinking 3×.
long_sideWorking resolution. 2048 for wide backgrounds is sharper, at about twice the time.
keep_glyphAfter the restyle, put back the original's saturated non-gold pixels inside the tile face. Glyph colours stay exact.

How a Spine page is restyled

A Spine page packs many parts into one PNG. Restyled as one picture, neighbours would bleed into each other and the animation would show seams. So restyle_game.py reads the .atlas and restyles each part on its own:

  1. Cut the part out at its rectangle. Rotated parts are turned upright first.
  2. Sort it by name into one of three groups: keep effects, glows, flipbook frames and parts under 40 px; text letters; object everything else.
  3. Restyle it with the page's subject. The restyled static symbol is used as an IP-Adapter reference (weight 0.35), so the parts match the symbol.
  4. Paste it back into exactly the same footprint. Premultiplied-alpha pages are read and written premultiplied, so no glow fringes appear in Cocos.

Mesh attachments stay correct because their UVs point at the same rectangle. Nothing needs re-exporting from Spine.

Sorting rules in the plan

FieldExample from this game
keep_wordsglow, light, shine, spark, fire, smoke, blur, trail … — any part whose name contains one is left as is
sequence_pattern(?<!<prefix>)_\d{2,5}$ — numbered flipbook frames are kept, so they don't flicker. Pictures whose names only end in a number (distinct tiles, for example) get a look-behind for their prefix so they are restyled
text_names, text_prefixesParts that are words or single letters: win-banner words, the letters of an animated title
keep_partsSingle parts to leave alone, such as a ring effect or a character's face
partsOne part's own subject, strength, or "reference": false. Used for golden tile frames, glyph parts and creatures

Limits

Shapes are fixedAlpha is the original's, so a rectangular tile cannot become an arched stone tablet, and a character cannot become a sword. A new icon set needs new art drawn to new outlines, and for animated symbols new Spine parts.
Text barely movesKeeping letters exact means low strength. Buttons, prompts and win-banner words keep most of their old colours. A stronger change means checking every letter by eye.
Effects keep coloursGlows, sparks, fire bursts and additive layers are not repainted, because a repaint breaks additive blending. A non-AI hue shift is possible if the old orange or gold effects clash.
Flipbooks are keptFrames restyled one by one would flicker. Rotating coins, spins and sweep frames keep the original look.
Large pictures softenSDXL works at about 1024 px. Backgrounds made at 2048 and scaled to 3000 are a little softer than the source. A tiled upscale pass is the next step if this shows on desktop.
Seed varianceEach result depends on the seed (1225 by default). A weak picture is redone with --only <name> --force, a new subject or another --seed.
Not coveredBitmap fonts, particle colours set in prefabs, sounds, and hands or faces (skin repaints badly, so they are kept). Body-shape changes need a Spine artist.
Style driftThe model adds its own detail inside the shape: leaf carvings on bamboo tiles, a medallion on a panel. Review every sheet and tighten the subject ("no emblem in the middle") where the extra detail is unwanted.

Running it

cd AIGamestyle\_pipeline\tools
# ComfyUI must be running on 127.0.0.1:8188
python restyle_game.py ..\style_profiles\<plan>.json --dry-run              # how every file / part sorts
python restyle_game.py ..\style_profiles\<plan>.json --only <path part>   # pilot one picture
python restyle_game.py ..\style_profiles\<plan>.json                        # everything not done yet
python restyle_game.py ..\style_profiles\<plan>.json --only <name> --force   # redo one
python check_restyle.py <source> <output>                                       # drop-in check

Output goes to AIGamestyle\output\<name>. Before / after sheets are in its _previews folder. The tool never writes to the original game folder. To apply: back up the originals outside the engine's asset folder, copy only the changed pictures over them, and keep .meta, .atlas and .json as they are.

What review usually finds

  • A part restyled weaker than its static symbol. Banner tiles left at 0.55 stayed white while the reel tiles turned to stone. Give matching parts the same strength and options as the symbol.
  • Glyph colours drifting at the strength needed to change the body. Use keep_glyph.
  • The model inventing an emblem in an empty panel, even with "no emblem" in the prompt. If a sibling picture has the same shape and came out right, derive this one from it (same colours, hue-shifted) instead of fighting the prompt.
  • Two moons, extra figures. Name the single object in the subject and the unwanted one in negative.
